Frequently Asked

Everything you need to know before you download.

Is GlowberryClient free?

Yes. Completely free, forever. It's open source on GitHub and there are no ads, subscriptions, or paid tiers. Ever.

Is it a cheat client?

No. GlowberryClient is a launcher, not a cheat tool. Every module in the PvP Suite is client-side — it shows you information on your own screen but never sends anything to the server that would give you an unfair advantage.

Will it get me banned from servers?

Every module is visual-only. Server anti-cheats cannot detect features that only render on your screen. That said, always follow the rules of the servers you play on.

What Android versions are supported?

Android 8.0 and up on ARM64 devices. If your device runs Minecraft Bedrock, it can run GlowberryClient.

Do I need a server for Proximity Voice Chat?

No. Voice Chat works directly between devices — no relay, no hosting, no monthly fee. Just open the app, join a channel, and talk.

How do I make my own mods?

GlowberryClient supports .AntEgg mods written in C++, Lua, Java, or Kotlin. Documentation and the mod format spec are on the GitHub repository.
