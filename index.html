FAQ

Questions, answered.

Is GlowberryClient free?

Yes. Completely free, forever. Open source on GitHub — no ads, no subscriptions, no paid tiers.

Is it a cheat client?

No. GlowberryClient is a launcher, not a cheat tool. Every PvP module is client-side and never sends anything to the server that would give you an unfair advantage.

Will it get me banned?

Every module is visual-only. Server anti-cheats cannot detect features that only render on your own screen. That said, always follow the rules of the servers you play on.

What Android versions are supported?

Android 9.0 (API 28) or higher on 64-bit (arm64-v8a) devices. If your phone runs Bedrock, it runs GlowberryClient.

Do I need a server for Voice Chat?

No. Voice chat connects devices directly — no relay, no hosting, no monthly fee.

How do I make my own mods?

GlowberryClient supports .AntEgg mods written in C++ or Lua. Documentation is on the GitHub repository.
