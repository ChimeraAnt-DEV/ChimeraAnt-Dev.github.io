Privacy Policy

Last updated: October 2026

TL;DR — GlowberryClient does not collect, store, or transmit any personal data. Everything runs on your device.

What we collect

Nothing. GlowberryClient has no accounts, no sign-up, no analytics, no telemetry, and no remote logging. We do not know who you are, how often you use the app, or what you do inside it.

What stays on your device

  • Launcher settings and preferences
  • Imported Minecraft versions
  • Mods you install (.AntEgg, .so, .levipack)
  • Replay clips you record
  • Screenshots and any files you create through the launcher

None of this is uploaded anywhere. If you uninstall the app, it's gone.

Network connections

GlowberryClient makes network requests in two cases:

  • Update checks — the launcher and this website query GitHub's public API to see if a newer release exists. This sends your IP address to GitHub (the same as visiting any GitHub page). No identifying information is attached.
  • Proximity Voice Chat — when you enable Voice Chat, your device connects directly to other devices over UDP. Audio is peer-to-peer and never passes through our servers. There are no GlowberryClient servers carrying your voice.

Permissions and why we ask for them

  • Screen recording (MediaProjection) — only when you tap Record. Powers Replay.
  • Microphone — only when Voice Chat is enabled. Audio is peer-to-peer.
  • Network access — for update checks and voice chat.
  • Storage — rarely requested. Only needed if you import a Minecraft version or save a replay clip. Your files never leave your device.
  • Notifications — optional, only for release alerts.

Third-party services

GlowberryClient does not integrate any third-party analytics, ad networks, or tracking SDKs. It uses the following public services directly:

  • GitHub — for source code, releases, and update checks.
  • GitHub Pages — to host this website.
  • Google Fonts — to load the Inter typeface on this site.

Each of these has its own privacy policy. GlowberryClient does not control what they log.

Children

GlowberryClient does not knowingly collect data from anyone. Since we collect no data at all, this applies to users of every age.

Changes to this policy

If this policy changes, the "last updated" date at the top will change. The source for both the app and this site is public on GitHub, so any change is visible in the commit history.
